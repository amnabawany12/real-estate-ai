# Real Estate AI - House Price Prediction

### Student: annabawang12

## 1. Project Overview
This project predicts house prices using Machine Learning.

## 2. EDA Completed
- Loaded 1460 houses data from train.csv
- Price Analysis: Checked SalePrice distribution
- Area vs Price: GrLivArea vs SalePrice (bigger house = more price)
- Location Comparison: Price by Neighborhood
- Property Trends: OverallQual and YearBuilt trends

## 3. Model
- Algorithm: Random Forest Regressor
- Accuracy: 83.95%
- Features: GrLivArea, OverallQual, YearBuilt

- EDA_REALESTATE.ipynb - Main notebook

- app.py - Web app
